# MH Flow — Frontend

رابط کاربری MH Flow بر پایه React، Vite، Tailwind CSS v4 و Capacitor.

## پیش‌نیازها
- Node.js سازگار با Vite 8 (Node.js 20.19+ یا 22.12+)
- npm

## اجرای توسعه
```bash
npm install
npm run dev
```

## ساخت نسخه انتشار
```bash
npm run build
```
خروجی وب در پوشه `dist` ساخته می‌شود.

## همگام‌سازی اندروید
```bash
npm run android:sync
```
برای ساخت APK باید Android SDK و ابزارهای Gradle در محیط ساخت موجود باشند. می‌توان از CI ابری استفاده کرد.

## وضعیت قابلیت‌ها
- ورود و ثبت‌نام فعلاً نمایشی است و به API متصل نیست.
- تنظیمات پروفایل و ترجیحات در Local Storage همین مرورگر ذخیره می‌شوند.
- گزارش باگ فعلاً در Local Storage ذخیره می‌شود و به سرور ارسال نمی‌شود.
- دانلود نسخه‌های Windows، Android و iOS تا انتشار فایل‌های رسمی غیرفعال است.
- صفحات برنامه‌ریز AI و تحلیل پیشرفته فعلاً وضعیت آماده‌سازی را نمایش می‌دهند.
- رابط تیمی و چت در این بسته به‌عنوان قابلیت عملیاتی پیاده‌سازی نشده‌اند؛ این نسخه فقط پایه فرانت‌اند را برای توسعه بعدی حفظ می‌کند.
